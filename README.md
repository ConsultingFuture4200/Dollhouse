# Baby Dollhouse

A 3D tap-to-play dollhouse for little kids (ages 3–4). Mommy, Daddy, Grandma, Grandpa, Brother and Sister care for fifteen babies and do household chores through short mini games. About 30% of play quietly mixes in counting, letters and "one more".

Plain static site: `index.html`, `game.js`, `style.css`. three.js r128 loads from cdnjs. No build step.

## Run locally

```
python3 -m http.server
```

Then open http://localhost:8000.

## Deploy

Linked to Vercel; every push to `main` redeploys.
